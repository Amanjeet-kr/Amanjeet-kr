Full-Stack Developer in Progress

I'm a CSE student who likes building things with code. Right now, I'm learning full-stack development and trying to get better by working on projects instead of just watching tutorials.

I mostly work on web development, but I'm also interested in backend systems, databases and how everything works behind the scenes. I like coming up with ideas and figuring out how to turn them into something that actually works.

### Tech Stack

- **Frontend:** HTML, CSS, JavaScript, React, Tailwind CSS
- **Backend:** Node.js, Express.js, Java, Spring Boot
- **Database:** MongoDB, MySQL
- **Tools:** Git, GitHub, Docker, VS Code

### Projects

- **MoonDrive** — Working on a cloud storage web app where uploaded files are stored on my own laptop, which acts as the server.
- **SarvDrishty** — An AI-based accessibility assistant that helps visually impaired users understand their surroundings using a camera and voice interaction.
- **Government Asset Management System** — A web platform idea to track government assets, report damage and help prioritise inspections.
- **Other projects** — Weather app, portfolio website, Tic-Tac-Toe and Stone Paper Scissors.

### What I'm learning

- Building better backend APIs with Java and Spring Boot
- Getting more comfortable with React and Node.js
- Working with databases and understanding how to structure data properly
- Learning Docker and deployment
- Improving my problem-solving and coding skills

### A few things about how I work

- I learn better when I build something myself.
- I prefer understanding the code instead of blindly copying it.
- I like experimenting with ideas, even if I have to start from scratch.
- There's always something to improve in a project, and that's part of the process.

Currently learning, building projects, and figuring things out one step at a time.
